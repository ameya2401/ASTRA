## 1. Overview

**ASTRA** is an automated pre-merge triage and risk-scoring platform that intercepts code pull requests generated by autonomous AI coding assistants (such as Devin, Claude Code, GitHub Copilot, and OpenHands) before human maintainers review them.

Standard test suites suffer from the **"Green CI Mirage"**: an AI agent pull request can pass syntax checks and test suites simply by deleting assertions, modifying fixtures, or inflating cyclomatic nesting. ASTRA extracts concrete syntax tree (CST/AST) structural deltas, NLP semantic intent alignment, and test tampering signals to predict defect risk in under 300ms using a Platt-calibrated XGBoost classifier with local TreeSHAP explanations.

## 3. The 28-Dimensional Feature Matrix

Every pull request is mapped into an empirical 28-D vector across four analytical pillars:

| Pillar | Features | Description |
| :--- | :--- | :--- |
| **AST Structural Churn** | `F01–F12` | Tree-sitter node churn, cyclomatic delta (&Delta;CC), max nesting depth delta, function signature changes, return type alterations, call graph fan-out delta, try/catch additions, and AST disturbance index. |
| **Semantic NLP Intent** | `F13–F18` | Sentence-Transformers `all-MiniLM-L6-v2` prompt-to-diff cosine similarity, issue title alignment, entity drift Jaccard index, docstring churn ratio, and binary semantic drift flag (< 0.45). |
| **Test Protection** | `F19–F23` | Test files touched, test AST nodes added, deleted test assertions, test-to-logic churn ratio, and mock/patch count delta. |
| **Process & Provenance** | `F24–F28` | Commit dispersion entropy, files touched, total commit count, CI pass status, and known agent bot login identifier. |

## 4. Quickstart Guide

### Prerequisites
- Python 3.11 or 3.12
- Git

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/ameya2401/ASTRA.git
cd ASTRA/ast-triage-core

# 2. Create and activate a virtual environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Initialize the async SQLite database schema
python -c "import asyncio; from database.connection import init_db; asyncio.run(init_db())"

# 5. Start the FastAPI backend and web interfaces
python -m uvicorn src.api.main:app --host 127.0.0.1 --port 8000
```

Once running, access the local services:
- **Product Landing Page:** [http://127.0.0.1:8000/landing/](http://127.0.0.1:8000/landing/)

## 6. Pre-Merge CI/CD GitHub Action Gate

To enforce automated merge gating in your GitHub repositories, place the following workflow at `.github/workflows/astra-gate.yml`:

```yaml
name: ASTRA Pre-Merge Risk Gate
on:
  pull_request:
    types: [opened, synchronize, reopened]

jobs:
  triage:
    name: Evaluate PR Risk
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Run ASTRA Triage Gate
        env:
          ASTRA_URL: ${{ secrets.ASTRA_API_URL || 'https://astra-08bw.onrender.com' }}
        run: |
          DIFF_DATA=$(git diff origin/${{ github.base_ref }}...HEAD)
          PAYLOAD=$(jq -n \
            --arg repo "${{ github.repository }}" \
            --arg pr "${{ github.event.pull_request.number }}" \
            --arg title "${{ github.event.pull_request.title }}" \
            --arg body "${{ github.event.pull_request.body }}" \
            --arg diff "$DIFF_DATA" \
            '{repo_name: $repo, pr_number: ($pr | tonumber), title: $title, issue_description: $body, raw_diff: $diff}')

          RESPONSE=$(curl -s -X POST "$ASTRA_URL/api/v1/triage/analyze" \
            -H "Content-Type: application/json" \
            -d "$PAYLOAD")

          RISK_TIER=$(echo "$RESPONSE" | jq -r '.risk_tier')
          PROB=$(echo "$RESPONSE" | jq -r '.risk_probability')

          echo "ASTRA Verdict: $RISK_TIER ($PROB defect probability)"
          if [ "$RISK_TIER" = "HIGH" ]; then
            echo "::error ::ASTRA Merge Blocked: PR classified as HIGH risk defect."
            exit 1
          fi
```
