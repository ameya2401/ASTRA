ASTRA Developer Documentation

ASTRA intercepts pull requests generated by AI coding agents (Devin, Claude Code, Copilot, OpenHands) before human review. It extracts concrete syntax tree deltas, NLP semantic drift, and test churn to classify defect risk with local TreeSHAP attribution.

1. System Overview

Standard CI suites and linters suffer from the Green CI Mirage: an AI agent pull request can pass syntax checks and unit tests simply by deleting assertions, modifying fixtures, or increasing cyclomatic nesting. ASTRA operates as a pre-merge triage barrier, evaluating 28 structural and semantic signals in under 300ms.

💡
Sub-300ms Inference SLA: All neural sentence embeddings (`all-MiniLM-L6-v2`) and Platt-calibrated XGBoost model checkpoints are pre-warmed as thread-safe singletons at application startup.

3. Authentication & Security

When integrating with GitHub Apps or webhooks, ASTRA authenticates incoming requests using HMAC SHA-256 signatures passed in the `X-Hub-Signature-256` header. For local development or internal service-to-service calls, standard JSON REST requests require no authentication.

4. API Reference

POST /api/v1/triage/analyze
Core Triage Engine

Ingests a pull request's unified diff, title, prompt specification, and provenance data. Computes concrete syntax tree deltas, semantic intent drift, and returns calibrated defect probability, risk tier (`LOW`, `MEDIUM`, `HIGH`), and local TreeSHAP attribution drivers.

Field Type Requirement Description
repo_name string required GitHub repository in `owner/repo` format.
pr_number integer required Pull request number.
title string required PR title summarizing the proposed modification.
issue_description string optional Original issue prompt or user instruction given to the AI agent.
raw_diff string required Unified git diff string containing file deltas.
author_login string optional GitHub login of the PR author (e.g. `devin-ai-integration[bot]`).
author_is_bot boolean default: false Whether author is a detected bot or automated agent.
Interactive Endpoint Console
GET /api/v1/triage/queue/{repo_name}
Review Prioritization

Retrieves the review queue for a repository sorted by defect risk score descending. Allows maintainers to prioritize high-risk pull requests requiring manual scrutiny before approving safe refactors.

Interactive Endpoint Console
GET /api/v1/triage/stats
System Statistics

Returns aggregate operational metrics across all triaged pull requests: total scanned, percentage categorized as high/medium/low risk, and average inference latency.

Interactive Endpoint Console
POST /api/v1/github/webhook
GitHub Ingestion

Receives native GitHub webhook `pull_request` payloads. Verifies webhook HMAC signature, fetches unified diff, runs AST risk classification, and posts an automated governance comment on the pull request.

GET /api/v1/health
Liveness & Readiness Probe

Returns health state confirming async database connectivity, XGBoost classifier readiness, and sentence transformer initialization.

5. 28-D Feature Matrix & Architecture

ASTRA converts every incoming pull request into an empirical 28-dimensional vector across four analytical pillars:

Pillar Feature IDs Primary Analytical Signals
AST Structural Churn F01–F12 Tree-sitter node churn, cyclomatic delta (ΔCC), max nesting depth delta, call graph fan-out delta, disturbance index.
NLP Semantic Intent Drift F13–F18 MiniLM cosine distance between issue prompt and code diff, entity drift Jaccard, docstring-to-code churn ratio.
Test Protection & Tampering F19–F23 Deleted assertion count, test-to-logic ratio, test AST nodes added, mock/patch count delta.
Process & Provenance F24–F28 Commit dispersion entropy, files touched, bot author flag, CI run status.

6. GitHub Action CI/CD Risk Gate

Enforce automated merge blocking in your repositories by placing the following workflow at `.github/workflows/astra-gate.yml`:

.github/workflows/astra-gate.yml
name: ASTRA Pre-Merge PR Risk Gate on: pull_request: types: [opened, synchronize, reopened] jobs: triage-pr: runs-on: ubuntu-latest steps: - name: Checkout Code uses: actions/checkout@v4 with: fetch-depth: 0 - name: Evaluate PR Risk Gate env: ASTRA_API_URL: ${{ secrets.ASTRA_API_URL || 'http://127.0.0.1:8000' }} run: | DIFF_CONTENT=$(git diff origin/${{ github.base_ref }}...HEAD) PAYLOAD=$(jq -n \ --arg repo "${{ github.repository }}" \ --arg pr "${{ github.event.pull_request.number }}" \ --arg title "${{ github.event.pull_request.title }}" \ --arg body "${{ github.event.pull_request.body }}" \ --arg diff "$DIFF_CONTENT" \ '{repo_name: $repo, pr_number: ($pr | tonumber), title: $title, issue_description: $body, raw_diff: $diff}') RESPONSE=$(curl -s -X POST "$ASTRA_API_URL/api/v1/triage/analyze" \ -H "Content-Type: application/json" \ -d "$PAYLOAD") RISK_TIER=$(echo "$RESPONSE" | jq -r '.risk_tier') if [ "$RISK_TIER" = "HIGH" ]; then echo "::error ::ASTRA Risk Gate Failed: PR classified as HIGH risk defect." exit 1 fi
