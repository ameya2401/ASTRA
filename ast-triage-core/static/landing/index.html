Why passing CI checks miss agent regressions

Empirical analysis of over 33,000 agent-authored pull requests (arXiv:2601.15195) found that automated submissions fail maintainer review even when build scripts and linters exit zero.

Conventional CI & Linters

Structural and intent blind spots

  • Linters check formatting, not control flow Flake8 and ESLint pass deeply nested conditional branches as long as indentation and syntax rules hold.
  • Test runners trust modified test files If an agent deletes failing assert statements or mocks out the system under test, pytest still exits zero.
  • Line counts hide semantic weight Plain git diff statistics treat a docstring edit the same as a function signature change or swallowed exception.
  • No comparison against the issue ticket Standard CI has no measure of whether the edited files relate to the task description.
ASTRA Pipeline

Pre-merge static verification

  • Tree-sitter concrete syntax differencing Walks base and head syntax trees with C-level cursors to isolate McCabe branching deltas, nesting depth, and signature edits.
  • Assertion suppression guardrails Tracks deleted assert statements against added test AST nodes, triggering a deterministic HIGH override when tests are stripped.
  • Local MiniLM intent alignment Embeds the issue prompt and normalized diff locally on CPU; cosine alignment below 0.45 flags off-topic edits without external API calls.
  • Calibrated scoring with TreeSHAP Platt scaling maps XGBoost margins to defect probabilities alongside exact feature attributions and function line hotspots.

Add ASTRA to a GitHub Repository

Drop this workflow into .github/workflows/astra-gate.yml to block pull requests flagged as HIGH risk before human review.

.github/workflows/astra-gate.yml 
name: ASTRA Risk Gate

on:
  pull_request:
    types: [opened, synchronize, reopened]

permissions:
  contents: read
  pull-requests: write
  statuses: write

jobs:
  triage:
    name: ASTRA AI-PR Risk Triage
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Run ASTRA Triage Inspection
        env:
          ASTRA_API_URL: "https://astra-08bw.onrender.com/api/v1/triage"
          PR_TITLE: ${{ github.event.pull_request.title }}
          PR_BODY: ${{ github.event.pull_request.body || '' }}
          AUTHOR: ${{ github.event.pull_request.user.login }}
        run: |
          git diff origin/${{ github.base_ref }}...HEAD > pr_diff.patch
          python3 -c "
          import json, os, urllib.request, sys
          payload = {
              'repo_name': '${{ github.repository }}',
              'pr_number': ${{ github.event.pull_request.number }},
              'pr_title': os.environ.get('PR_TITLE', ''),
              'pr_body': os.environ.get('PR_BODY', ''),
              'raw_diff': open('pr_diff.patch', 'r', errors='ignore').read(),
              'author_login': os.environ.get('AUTHOR', ''),
              'author_is_bot': False
          }
          req = urllib.request.Request(
              os.environ['ASTRA_API_URL'],
              data=json.dumps(payload).encode('utf-8'),
              headers={'Content-Type': 'application/json'}
          )
          with urllib.request.urlopen(req, timeout=30) as resp:
              res = json.loads(resp.read().decode('utf-8'))
          print(f'ASTRA Verdict: {res[\"risk_tier\"]} ({res[\"risk_probability\"]:.1%})')
          if res.get('risk_tier') == 'HIGH' and res.get('risk_probability', 0) >= 0.65:
              sys.exit(1)
          "
